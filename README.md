# Intelligent Financial Advisor using ML and Neural Networks

## Project Overview
This project builds an AI system that analyzes a person's income and expenses to predict financial risk level and provide investment advice.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TensorFlow / Keras
- Matplotlib

## Machine Learning Models
- Random Forest Classifier
- Neural Network

## Features
- Predict financial risk level
- Recommend investment strategies
- Visualize expense distribution

## Results
Random Forest Accuracy: 0.97  
Neural Network Accuracy: 0.67

## Dataset
Financial dataset from Kaggle.
